## Revision history

- **v1**: Initial 2500-question set generated from Splunk Enterprise 10.4 Simple XML dashboards documentation, distributed proportionally by topic size.
- **v2**: Fixed 9 duplicate/near-duplicate questions found via spot-check and systematic similarity sweep; fixed 2 meta-referential phrasing issues.
- **v3**: Reworded ~750 questions (30% of the set) that were phrased as "per the documentation," "according to the documentation," "what does the documentation say/recommend/state about X," or similar. These phrasings made a question's answerability depend on having read this specific documentation passage rather than testing standalone knowledge of the feature. Questions were rewritten as direct, self-contained questions (e.g., "What is the default value of X?" instead of "What is the default value of X, per the documentation?"); the underlying facts, options, and correct answers were not changed, only the question framing.

## Notes

- Questions were distributed proportionally across topics based on the size (word count) of each topic's source documentation, per the original task instructions.
- Each question has four options (A–D); answer-key letters were pre-generated to be evenly distributed (625 of each) before questions were written, so the correct answer is not biased toward any position.
- All options within a question were checked to avoid answer-length bias (the correct option is not systematically longer or shorter than the distractors).
- Source material: Splunk Enterprise 10.4 "Simple XML dashboards" documentation (Simple XML dashboards manual), covering dashboard/form structure, visualizations (tables, charts, maps, single values, gauges, trellis), searches, drilldown and interactivity, dashboard management/sharing, and the full Simple XML/Event Handler/Chart Configuration/Token references.
